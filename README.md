## Browser Automation Frameworks

Open-source frameworks and libraries for controlling browsers.

- [Playwright](https://github.com/microsoft/playwright) - Browser automation framework for Chromium, Firefox, and WebKit.
- [Selenium](https://github.com/SeleniumHQ/selenium) - Browser automation framework and WebDriver ecosystem.
- [Puppeteer](https://github.com/puppeteer/puppeteer) - Node.js library for controlling Chrome and Chromium.
- [Cypress](https://github.com/cypress-io/cypress) - JavaScript end-to-end testing framework.
- [WebdriverIO](https://github.com/webdriverio/webdriverio) - Browser and mobile automation framework for Node.js.
- [TestCafe](https://github.com/DevExpress/testcafe) - End-to-end testing framework for web applications.
- [Nightwatch](https://github.com/nightwatchjs/nightwatch) - End-to-end testing framework powered by WebDriver.
- [Taiko](https://github.com/getgauge/taiko) - Node.js browser automation library.
- [CodeceptJS](https://github.com/codeceptjs/CodeceptJS) - Acceptance testing framework with a high-level API.

## AI Browser Automation

Tools that help AI agents inspect, control, or automate browsers.

- [Vibium](https://github.com/VibiumDev/vibium) - Browser automation for AI agents and humans.
- [Browser Use](https://github.com/browser-use/browser-use) - Python library for AI agents that interact with browsers.
- [Skyvern](https://github.com/Skyvern-AI/skyvern) - AI browser automation tool for automating browser workflows.
- [Stagehand](https://github.com/browserbase/stagehand) - AI browser automation framework built around Playwright.
- [Playwright MCP](https://github.com/microsoft/playwright-mcp) - MCP server that gives AI agents browser automation capabilities through Playwright.
- [Steel Browser](https://github.com/steel-dev/steel-browser) - Browser API and sandbox for AI agents.
- [Browserbase](https://www.browserbase.com) - Cloud browser infrastructure for browser automation and AI agents.
- [Browserless](https://www.browserless.io) - Hosted browser automation infrastructure for Puppeteer and Playwright.

- [Leapwork](https://www.leapwork.com) - Visual test automation platform.

- [Robot Framework](https://github.com/robotframework/robotframework) - Generic open-source automation framework for acceptance testing and RPA.
- [Gauge](https://github.com/getgauge/gauge) - Lightweight cross-platform test automation framework.

## Browser Automation Protocols

Protocols and standards used by browser automation tools.

- [WebDriver](https://www.w3.org/TR/webdriver2/) - W3C browser automation protocol.
- [WebDriver BiDi](https://www.w3.org/TR/webdriver-bidi/) - Bidirectional browser automation protocol.
- [Chrome DevTools Protocol](https://chromedevtools.github.io/devtools-protocol/) - Protocol for inspecting, debugging, and automating Chromium-based browsers.
